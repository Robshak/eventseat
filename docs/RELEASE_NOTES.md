EventSeat 1.1 — обновление удобства локального настольного приложения для Windows 10/11 x64.

- Подсветка при наведении на кнопки, навигацию, карточки и места.
- Переход к мероприятию из корзины и бронирования; сохранён доступ к описанию снятого события и к историческому билету.
- Переключатель уже вошедших аккаунтов слева и «Добавить аккаунт». Входы действуют до закрытия приложения; пароли для переключения не сохраняются.
- Выход перенесён в профиль, убрана дублирующая подпись «Личный кабинет».
- Администратор управляет событиями и просматривает схемы без возможности бронирования. Ограничение действует и в сервисе.
- Поиск по интервалу «С» / «По» с календарями и включёнными границами; цена и дата карточки учитывают интервал.

Скачайте **EventSeat.exe** и запустите. Python и установка зависимостей не нужны. При первом запуске задайте собственный аккаунт администратора. Пользовательские данные сохраняются в `%LOCALAPPDATA%\EventSeat`.

База версии 1.0 сохраняется при обновлении; изменения схемы не требуются. Для проверки бронирования под администратором нажмите «Добавить аккаунт» и создайте посетителя.

Перед упаковкой проходят pytest и проверки Ruff. Готовый EXE проходит создание администратора, конструктор зала, публикацию мероприятия, регистрацию пользователя, переключение аккаунтов, фильтрацию дат, переходы к событиям, оформление билета, закрытие процесса, повторный вход и отмену. Снимки экранов и отчёты доступны в артефакте EventSeat-verification соответствующего запуска Actions.

SHA-256 прилагается отдельным файлом. Бронирование не является оплатой; серверной синхронизации нет. Учебный льготный тариф — скидка 20%. Электронный билет открывается внутри приложения. Проверка выполнена на Windows 11 x64; отдельный прогон на Windows 10 не выполнялся.
