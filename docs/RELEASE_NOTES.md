EventSeat 1.2 — навигация между событиями, сеансами и залами, сохранение форм и групповое редактирование схемы для Windows 10/11 x64.

- Наведение больше не меняет размеры рамки и не сдвигает соседние элементы.
- Переключатель аккаунтов получил читаемые подписи и видимую рамку.
- Нажатие на мероприятие в администрировании открывает список его сеансов. Кнопка «Создать сеанс» явно запускает создание; существующие сеансы показывают дату, время и зал.
- Сеанс ведёт к мероприятию и настройкам зала; из зала доступны сеансы, в которых он используется.
- Переход из афиши к управлению конкретным сеансом прокручивает список и выделяет нужную карточку.
- В конструкторе зала свойства кресла открываются справа. Shift + клик выделяет прямоугольник, Ctrl + клик добавляет или убирает место. Категорию, индивидуальную цену и кресло/проход можно применить сразу ко всей группе.
- Страницы запоминают вкладки, прокрутку и незавершённые формы отдельно для каждого аккаунта до закрытия приложения. Выход из аккаунта очищает его черновики; парольные поля не сохраняются.
- Статистика фильтруется по мероприятию, залу, сеансу, периоду и статусам сеансов и бронирований. Отменённые билеты учитываются в выбранной истории и не увеличивают заполнение.
- Электронный билет открывает схему с отмеченными местами, мероприятие и конкретный сеанс. Новые бронирования сохраняют собственную геометрию зала независимо от последующих изменений.

Скачайте **EventSeat.exe** и запустите. Python и установка зависимостей не нужны. При первом запуске задайте собственный аккаунт администратора. Пользовательские данные сохраняются в `%LOCALAPPDATA%\EventSeat`.

Обновление автоматически переводит базу на схему 4. Перед заменой EXE закройте приложение и сохраните копию папки данных. Аккаунты, корзины и билеты остаются в базе. Для старых бронирований, исходная схема которых уже утрачена, отображаются достоверные места из билета с предупреждением о неполной геометрии.

Сборка проходит pytest, Ruff и проверку готового EXE в двух процессах с сохранённой базой. Отчёты и снимки работающего интерфейса доступны в артефакте EventSeat-verification соответствующего запуска Actions. SHA-256 прилагается отдельным файлом.

Бронирование не является оплатой; серверной синхронизации нет. Учебный льготный тариф — скидка 20%. Электронный билет и схема доступны внутри приложения. Основная проверка выполняется на Windows 11 x64; отдельный прогон на Windows 10 не заявляется.
