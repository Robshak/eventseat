EventSeat 1.3 — прямое редактирование сеансов, общая страница бронирований и упрощённые цены залов для Windows 10/11 x64.

- Меню аккаунтов открывается вверх внутри левой панели. Длинный список прокручивается; меню закрывается по Esc или нажатию снаружи.
- Карточка сеанса сразу открывает редактор. Заголовки карточек больше не дублируют действие отдельной ссылкой. Из формы доступны мероприятие и зал; отменённые и прошедшие сеансы открываются для просмотра.
- В администрировании четыре вкладки. «Бронирования» объединяет метрики и список с общими фильтрами по событию, залу, сеансу, датам, состояниям и номеру/владельцу брони.
- Поиск и состояние брони одинаково меняют список, количество и сумму. Заполненность отдельно показывает занятые места всех выбранных сеансов без отменённых билетов.
- Цены задаются только по категориям в конструкторе зала. Настройки индивидуальной цены и отдельный редактор цен сеанса убраны. Новый сеанс получает цены своего зала; существующие снимки не пересчитываются.
- Новый календарь выбирает календарный день без смещения из-за часового пояса. Поле даты автоматически добавляет точки, поддерживает вставку и исправление частей даты, сохраняет положение курсора и показывает ошибки ввода.
- Незавершённые формы, выделение кресел, фильтры и прокрутка сохраняются отдельно для каждого аккаунта в текущем запуске. Ошибочная незавершённая дата не заменяет последний применённый фильтр.

Запустите **EventSeat.exe**: установленные Python и uv не нужны. При первом запуске задайте собственный аккаунт администратора. Для бронирования добавьте аккаунт посетителя. Данные находятся в `%LOCALAPPDATA%\EventSeat`.

При обновлении база автоматически переходит на схему 5. Миграция очищает индивидуальные цены только в шаблонах залов. Старые цены мест в сеансах, суммы корзин и оформленные билеты остаются прежними. Перед заменой EXE закройте приложение и сохраните копию папки данных.

Скрипт сборки выполняет pytest и Ruff; проверка готового EXE запускает его в двух отдельных процессах с тестовой базой. Результаты конкретного прогона публикуются в `docs/TESTING.md` и артефактах соответствующего запуска Actions. Контрольная сумма распространяемого файла находится в `SHA256SUMS.txt`.

Бронирование не является оплатой; серверной синхронизации нет. Учебный льготный тариф — скидка 20%. Электронный билет и схема доступны внутри приложения. Отдельный прогон новой версии на Windows 10 не заявляется.
