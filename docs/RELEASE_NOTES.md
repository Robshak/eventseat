EventSeat — локальное настольное приложение для Windows 10/11 x64. Русский интерфейс, афиша, несколько залов и сеансов, конструктор кресел и проходов, точные цены, личные корзины, электронные билеты, история и административная панель.

Скачайте **EventSeat.exe** и запустите. Python и установка зависимостей не нужны. При первом запуске задайте собственный аккаунт администратора. Пользовательские данные сохраняются в `%LOCALAPPDATA%\EventSeat`.

Перед упаковкой проходят 82 теста pytest и проверки Ruff. Готовый EXE проходит создание администратора, конструктор зала, публикацию мероприятия, регистрацию пользователя, оформление билета, закрытие процесса, повторный вход и отмену. Снимки экранов и отчёты доступны в артефакте EventSeat-verification соответствующего запуска Actions.

SHA-256 прилагается отдельным файлом. Бронирование не является оплатой; серверной синхронизации нет. Учебный льготный тариф — скидка 20%. Электронный билет открывается внутри приложения. Проверка выполнена на Windows 11 x64; отдельный прогон на Windows 10 не выполнялся.
