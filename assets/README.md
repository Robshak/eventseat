# Ресурсы EventSeat

`cinema.png`, `concert.png`, `lecture.png` и `eventseat.ico` — собственные геометрические иллюстрации проекта. Они включены в автономную сборку и не требуют интернета. Скрипт `scripts/create_assets.py` воспроизводит иллюстрации с помощью Pillow; на Windows используется системный Segoe UI, файл шрифта не распространяется.

Обложки пользователя копируются в каталог данных приложения. Отсутствующее изображение заменяется нейтральной карточкой в интерфейсе.
